# Для агентов и разработчиков

Прототип CQA: оценка диалогов операторов Freedom Broker по настраиваемому чек-листу. Что делает продукт и как его запустить — в `README.md`.

## Где что лежит

- `cqa/` — оценщик: промпт и JSON-схема из чек-листа (`prompt.py`, `schema.py`), факты из событий диалога (`facts.py`), ступени по фактам (`derive.py`), проверка доказательств (`verify.py`), расчёт баллов (`scoring.py`), вызовы модели и голосование (`evaluator.py`).
- `app/` — продукт: HTTP API и пул оценки (`server.py`), SQLite (`store.py`), подсказка и второе мнение (`assist.py`), суфлёр и тренажёр (`copilot.py`), прямой эфир (`live.py`), голос оператора (`voice.py`), карта навыков (`operators.py`).
- `public/` — интерфейс без сборки: `index.html`, `cqa.css`, `js/pages/*.js`.
- `config/checklist.default.json` — чек-лист организаторов; `data/gold/` — рабочая разметка команды (не официальный эталон).
- `docs/ACCURACY.md` — замеры точности; `docs/decision-log.md` — решения; `docs/history/` — история переноса и прошлых сессий.

## Правила

- Чек-лист меняется через интерфейс, без правки кода: новые правила толкования — общие формулировки из чек-листа, не исключения под конкретные диалоги DEV.
- Итог, перераспределение веса N/A и округление считает код, не модель.
- Не коммитить ключи, `.env`, `data/raw/` (подписанные адреса организаторов), `data/runs/`, базу `data/*.db`.
- Перед коммитом: `python -m pytest -q`. Платные прогоны — только по запросу и с оценкой стоимости заранее.
