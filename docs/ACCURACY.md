# Точность оценщика

Эталон — рабочая разметка команды v4.1 (три независимых голоса по спорным местам), а не ответы организаторов.

## Рекомендуемая конфигурация

```bash
python scripts/run_eval.py --model claude-opus-5-5 --effort high --votes 3 --workers 4
```

Чек-лист `config/checklist.default.json` версии 8, без примеров в промпте. Около $0,13 за диалог при трёх голосах. При `--workers` больше 4 API начинает отвечать ошибкой лимита — недоделанное догоняется через `--resume`.

## Результаты (Opus 5.5)

| Проверка | v5, 1 голос | v7, 1 голос | v8, 3 голоса | v9 (ступени считает код), 1 голос |
|---|---|---|---|---|
| DEV, средняя точность по критериям | 92,1% | 93,6% | **94,4%** | **94,4%** |
| DEV, все 8 оценок совпали | 40/65 | 39/64 | **45/65** | 44/65 |
| DEV, отклонение итога (MAE) | 4,55 | 4,50 | **3,65** | 4,46 |
| Метаморфные тесты (не зависят от эталона) | 31/34 | 34/34 | 34/34 | **18/18** (3 исходника) |
| Контрастные диалоги вне DEV | — | 8/8 | 8/8 | **8/8** |
| Диалоги на выявление потребности вне DEV | — | 8/8 | 8/8 | **8/8** |

v8 по критериям на DEV: контакт, идентификация, грубые ошибки — 100%; эмпатия, завершение — 97%; выявление потребности — 92%; консультация — 89%; ведение диалога — 80%.

v9: для выявления потребности, консультации и ведения диалога модель отдаёт факты (какие вопросы задал клиент, закрыт ли каждый, какие были сбои), а ступень по правилам чек-листа выводит код (`cqa/derive.py`). Один голос v9 даёт ту же среднюю точность, что три голоса v8, то есть втрое дешевле. По сравнению с одним голосом v7: консультация 84% → 88%, ведение диалога 83% → 86%. Против трёх голосов v8: ведение диалога 80% → 86%; выявление потребности 92% → 91% и консультация 89% → 88% — разница в один диалог, в пределах разброса одного голоса. Метаморфные тесты стали стабильнее: на соседних критериях 1 сдвиг вместо 10. Оставшиеся промахи по выявлению потребности — спорные «переспросил известное» (p1-kz-003, p1-ru-017 — кандидаты на слепую переразметку). Стоимость прогона DEV — $2,8.

## Как избегали подгонки под DEV

- Подсказки в чек-листе — только общие правила из текста чек-листа и памятки; проверено, что в них нет фраз из DEV.
- Без примеров из DEV в промпте.
- Независимые проверки: метаморфные тесты (`scripts/run_metamorphic.py`, ожидание считается от ответа модели на исходный диалог) и наборы `data/calibration/*` с известными ответами.
- DEV-цифры — оценка сверху: правила v6–v8 правились по ошибкам на DEV. Ориентир для новых данных — независимые проверки.
