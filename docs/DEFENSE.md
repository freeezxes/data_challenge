# Демонстрация за 5 минут

Порядок показа по плану из гайда организаторов: четыре блока, все функции — внутри них.

## Подготовка

После выдачи контрольного набора:

1. Главная → «Загрузить по group_id» → значение от организаторов.
2. Очередь → набор контрольных диалогов → режим «3 прогона» → «Оценить неоценённые». 10 диалогов — около 2 минут, около $1,5.
3. Выбрать для показа чат, где есть и снижение, и «Не применяется»; для апелляции — критерий со спорной оценкой («Модель сомневается»).
4. Сохранить копию базы, чтобы после репетиций вернуть чистое состояние:
   - Windows: `copy data\cqa.db data\cqa.demo.db`
   - macOS / Linux: `cp data/cqa.db data/cqa.demo.db`

Перед выступлением:

- [ ] Сервер запущен, в терминале «ключ API: есть»; одна пробная оценка прошла.
- [ ] Апелляций «Ждут решения» — 0, роль — «Оператор».
- [ ] Масштаб браузера 110–125%, проверен на проекторе.
- [ ] Запасной канал интернета; запись экрана с прогоном сценария на случай сбоя сети.

## Порядок

| Время | Блок | Действия |
|---|---|---|
| 0:00–1:00 | Интерфейс и диалог | Очередь контрольного набора, фильтры. Открыть диалог → «Оценить заново»: справа прямой эфир, критерии появляются по мере того, как модель их пишет. |
| 1:00–3:00 | Оценка, обоснование, N/A, итог | Баллы, объяснения и цитаты. «Перейти к …» — переход к реплике. Критерий «Не применяется» и перераспределённый вес. Итог и флаг грубого нарушения. «Как получена оценка». Звонок: клик по волне — переход к месту записи. |
| 3:00–4:00 | Апелляция | «Оспорить» у критерия с комментарием → роль «Проверяющий» → «Апелляции» → второе мнение модели → «Изменить оценку» с причиной → новый итог, в карточке исходная оценка и решение. |
| 4:00–5:00 | Замена критерия | «Чек-листы» → критерий → формулировки, тип, N/A, вес (сумма 100) → «Сохранить версию» → «Применить к набору» → диалоги оцениваются по новой версии. |

## Если что-то пошло не так

| Ситуация | Что делать |
|---|---|
| Прямой эфир дольше 30 секунд | Открыть предыдущую оценку этого диалога из истории в шапке карточки. |
| Нет сети или ошибка API | Запасной канал; если не помогло — запись экрана. Готовые оценки, апелляции и чек-листы работают без API. |
| Второе мнение не приходит | Выбрать ступень вручную — апелляция работает и без него. |
| Версия чек-листа не сохраняется | Причина написана внизу; чаще всего сумма весов не равна 100. |
| Не хватает времени | Пропустить «Как получена оценка», звонок и второе мнение. |
