# Data Challenge — локальный просмотрщик

Запуск: `node server.mjs` и открыть http://127.0.0.1:4317.
Нужен Node.js 22+. Зависимостей нет. Сервер слушает только loopback.

`public/dataset.json` — снимок DEV-набора организаторов Data Challenge от 7 ноября 2026: 65 диалогов. Чаты синтетические, звонки реальные по описанию задания. Тексты не редактировались. Набор и ссылки на записи предназначены для локального просмотра; публикация не выполнялась.

Поиск работает по ID и всем репликам, язык и канал фильтруют список. Контекст бота/системы можно скрыть. JSON и текст текущего диалога доступны для копирования. Оценка качества не реализована.
