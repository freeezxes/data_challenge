## Автоматический оценщик и сравнение

1. Уже сохранено Python-ядро оценщика Claude из GitHub. Согласовать правила (включая исключение порога первой реакции 3 минуты), модель и способ вызова; зафиксировать параметры, задержку и стоимость всех вызовов на диалог.
2. Передавать критерии из сохранённой конфигурации, а не зашивать восемь специальных промптов. Версионировать чек-лист и результат.
3. Возвращать структурированные значения, объяснения, индексы/диапазоны сообщений и причины N/A. Проверять допустимость шкал, наличие доказательств и корректность ссылок.
4. Итог считать детерминированно по весам и N/A вне модели. Грубые ошибки — отдельный флаг.
5. Harness сравнивает значения по каждому критерию, N/A, грубые ошибки, итог и ссылки-доказательства. Результаты показывать отдельно по RU/KZ/EN и чатам/звонкам; спорные метки анализировать отдельно.
6. Собственная разметка служит ориентиром для диагностики. Если она использовалась при настройке, не представлять совпадение на ней как независимое качество на новых данных.

## Обязательный продуктовый контур

1. Сохранение и редактирование чек-листа через UI: название, правило, вес, тип, шкала, N/A; запуск оценки после замены критерия.
2. Загрузка DEV/контрольного набора и запуск оценки; ошибка API, повтор и понятный статус обработки.
3. Результат рядом с диалогом, переход к реплике или фрагменту звонка; исходный транскрипт сохраняется.
4. Апелляция с комментарием → решение проверяющего и причина → новый итог; сохранение исходной и финальной оценки.
5. Демонстрация замены одного критерия без кода на незнакомых диалогах.

## Подготовка сдачи

Проверить весь путь на RU/KZ/EN, N/A, грубое нарушение, спорную апелляцию, звонок и замену критерия. Для UI посмотреть реальный desktop/mobile рендер и клавиатурный фокус. Затем обновить README, стоимость оценки и пяти минутный сценарий защиты. Публикация, отправка ссылки и фиксация финального коммита выполняются отдельными явными действиями.

Ориентиры организаторов: контрольные данные через 23 часа, стоп-код через 24 часа после официального старта. Абсолютное время старта ещё нужно сверить с объявлением.
