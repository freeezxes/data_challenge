# Сверка разметки Claude и ChatGPT (Codex): кто прав

## Где прав Claude

**07 «Завершение», 27 расхождений — вопрос политики.** ChatGPT применяет буквальную трактовку (только итог или предложение помощи). Тогда безупречный `p1-kz-001` («Оқасы жоқ. Сау болыңыз!») и `p1-kz-004` с голым «Сау болыңыз!» получают одинаковое «Нет». Между тем в KZ-наборе четыре чата, которые отличаются от идеальных только голым прощанием: так выглядят тесты на 07. Буквальная политика доступна флагом `--policy strict`; финальный ответ — за менторами.

## Обоснования и тест на чушь

У каждой из 520 оценок есть реплики-доказательства, дословная цитата и пояснение (`rationale` в `dev_gold.json`). Проверка `cqa/verify.py` (тест `tests/test_bullshit.py`) ловит:
- выдуманные цитаты и несуществующие ID реплик;
- бессодержательные цитаты (например, цифру из голосового меню);
- провал критерия без реплики оператора;
- «Контакт» без первой реплики оператора;
- «Идентификация = Да» без события подтверждения;
- «Завершение = N/A» без события обрыва.

Тот же код проверяет ответы модели в оценщике.
