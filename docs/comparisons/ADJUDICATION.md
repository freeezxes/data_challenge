Сау болыңыз!») и `p1-kz-004` с голым «Сау болыңыз!» получают одинаковое «Нет». Между тем в KZ-наборе четыре чата, которые отличаются от идеальных только голым прощанием: так выглядят тесты на 07. ## Обоснования и тест на чушь

У каждой из 520 оценок есть реплики-доказательства, дословная цитата и пояснение (`rationale` в `dev_gold.json`). Проверка `cqa/verify.py` (тест `tests/test_bullshit.py`) ловит:
- выдуманные цитаты и несуществующие ID реплик;
- бессодержательные цитаты (например, цифру из голосового меню);
- провал критерия без реплики оператора;
- «Контакт» без первой реплики оператора;
- «Идентификация = Да» без события подтверждения;
- «Завершение = N/A» без события обрыва.

Тот же код проверяет ответы модели в оценщике.

## Сверка с прогонами модели (эталон v3.1)

Собраны все расхождения модели с эталоном из калибровок Codex (22 места). Большинство — ошибки модели, разобраны в `calibration-*.json`. Одно семейство повторилось во всех источниках: модель, исходная разметка ChatGPT и разбор Codex ставят «Нет» по эмпатии, когда оператор отмахивается от вопроса клиента. Это совпадает с нашим же правилом «пренебрежение — Нет», поэтому эталон исправлен:

| Диалог | Крит. | Было | Стало | Реплика |
|---|---|---|---|---|
| p1-ru-003 | 05 | Да | Нет | m15 «Название тарифа смотрите там же» на повторный вопрос о комиссии |
| p1-ru-007 | 05 | Да | Нет | m13 «Путь к обновлению я указал» |
| p1-en-007 | 05 | Да | Нет | m12 «That's where the profile request is» |

Не изменено, хотя модель предлагала: требование срока ответа для 20 по консультации (p1-ru-006, p1-ru-010), «косвенный ответ — 15» (p1-ru-012, p1-ru-021), «завершение возможно за 18 секунд до обрыва» (p1-ru-012). Автоматические проверки согласованности (вопрос в первом ответе при N/A по 02, переспрос клиента при ведении 10, недовольство клиента при эмпатии «Да») новых ошибок не нашли.
Средний итог DEV: 84,1; RU 81,0, KZ 88,4, EN 86,9. Расхождений с исходной разметкой ChatGPT: 34 из 520.
