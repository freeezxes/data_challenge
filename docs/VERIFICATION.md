# Проверка переноса 7 ноября 2026

Проверки выполнены из корня `data_challenge`.

- `python3 annotations/build.py` пересобирает разметку без файлов из `/private/tmp` или старой рабочей папки. Результат совпал с импортированным JSON источника.
- Проверено покрытие всех 65 диалогов и по 8 критериев на каждый; исходный набор содержит 1 268 реплик.
- SHA-256 набора, PDF чек-листа и каждого транскрипта совпадают с provenance разметки. Индексы, роли, время и тексты всех цитат-доказательств совпадают с исходными репликами.
- Итоги совпадают с пересчётом по сохранённым применимым весам. Это проверка расчёта, а не независимое подтверждение правильности оценок ассистента.
- Все пять сопоставлений записей указывают на существующие MP3. Range-запрос на 128 байт возвращает HTTP 206 и 128 байт.
- Сервер из этого репозитория запущен на `127.0.0.1:4318`; HTML, JS, CSS, шрифт и JSON доступны по HTTP 200.
- `node --check` прошёл для сервера, главного интерфейса и страницы разметки.
- Страница «Наша разметка» открыта в браузере из нового репозитория. В реальном рендере видны 65/65, список диалогов, статусы, баллы и спорные решения. Это проверка переноса; полный аудит desktop/mobile и всех действий нового раздела здесь не проводился.

Исходная сессия во время переноса ещё работала над проверкой UI. Снимок файлов и время последней синхронизации сохранены в `import-manifest.json`. Коммиты и push не выполнялись.
