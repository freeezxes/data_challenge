# Прогоны v12

Сырые результаты последней версии оценщика: Claude Opus 5.5, effort high, три прогона, при расхождении добор до пяти, чек-лист организаторов. В каждом файле — ответы модели по прогонам, итоговые ответы, баллы, цитаты, токены и стоимость, хэши промпта, чек-листа и набора.

| Файл | Что | Итог | Стоимость |
|---|---|---|---|
| `dev.json`, `dev.report.json` | DEV, 65 диалогов — регрессия, сверка с рабочей разметкой команды | 94,6% по критериям, все 8 совпали в 45 из 65; 520 из 520 оценок с проверенной цитатой | $10,95 |
| `metamorphic.json` | Метаморфные тесты: 8 правок × 3 диалога | 24 из 24 | $5,23 |
| `checklist-pairs.json`, `.report.json` | Пары диалогов из текста чек-листа (`data/calibration/checklist-pairs*.json`) | 18 из 19, одна пара спорная | $1,58 |
| `checklist-pairs-c01.json`, `.report.json` | Повтор после исправления пары по приветствию | — | $0,07 |

Стоимость посчитана по usage из ответов API с запасом; фактический счёт в консоли ниже.

Посмотреть в интерфейсе:

```bash
.venv/bin/python -m app.import_run data/results/v12/dev.json
```

Пересчитать отчёт без вызовов модели: `.venv/bin/python scripts/run_eval.py --compare-only data/results/v12/dev.json`. Подробности и история версий — [docs/ACCURACY.md](../../../docs/ACCURACY.md).
